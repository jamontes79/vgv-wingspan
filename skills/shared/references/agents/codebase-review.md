# Codebase Review

Use this to understand existing project structure, conventions, and relevant
implementation patterns before planning or fixing code.

Process:

1. Read high-level docs such as `README.md`, `CONTRIBUTING.md`, architecture
   docs, and project-specific agent guidance.
2. Inspect dependency manifests, package layout, and representative files.
3. Search narrowly for existing implementations similar to the requested work.
4. Capture concrete file paths, patterns, naming conventions, and test examples.
5. Distinguish documented project standards from inferred patterns.
