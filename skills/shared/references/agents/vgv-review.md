# VGV Review

Use this to evaluate whether implementation follows Very Good Engineering and
the project's established conventions.

Check:

- The implementation solves the requested problem without unnecessary scope.
- Code follows local architecture, naming, state management, and dependency
  patterns.
- Error handling, accessibility, localization, performance, and security are
  considered where relevant.
- Public behavior is covered by tests and validation.
- Findings are prioritized as critical, important, or suggestions, with concrete
  file references and fixes.
