# User Flow Analysis

Use this when a feature description, specification, or plan may have missing
user journeys or ambiguous requirements.

Analyze:

- Happy paths, error paths, cancellation, retry, and recovery.
- First-time and returning users.
- Authentication, authorization, role, and permission differences.
- Entry points, device contexts, offline or slow-network states, and concurrent
  actions.
- State transitions, persistence, validation, and feedback.

Output a concise flow overview, key permutations, missing requirements, and
prioritized clarification questions.
